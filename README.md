# BlockSphere — Blockchain Landing Page

A responsive, student-friendly landing page that introduces blockchain and Web3 through clear explanations, a custom SVG network illustration, and lightweight interactions.

## Features
- Responsive layout for desktop, tablet, and mobile
- Custom blockchain network illustration made with inline SVG
- Simple explanations of blockchain, decentralization, transparency, smart contracts, and Web3
- Real-world examples: supply chains, digital identity, and decentralized finance
- Working anchor navigation and mobile menu
- Scroll-reveal animations with reduced-motion support
- No framework or build step required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, responsive styles, and animations
- `script.js` — mobile navigation and scroll-reveal interactions

## Design choices
The dark navy background gives the page a focused technical feel. Lavender and mint accents suggest connected networks without overwhelming the content. Space Grotesk is used for readable, distinctive headings, while DM Mono labels create a subtle technical contrast. The network illustration is drawn directly in SVG so it stays crisp at different screen sizes. Content is organized as a short learning journey instead of a large grid of generic cards.

## AI tools
AI assistance was used to help draft and refine the initial page structure, copy, and implementation. Review and adapt the code before submitting, and be prepared to explain the SVG illustration, responsive CSS, navigation logic, and Intersection Observer animation.
